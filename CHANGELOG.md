# Changelog

All notable changes to iWeather are documented here.

## 1.0.0 - 2026-09-04

- Add current conditions, hourly forecasts, and five-day forecasts.
- Add city and ZIP-code search with persistent location selection.
- Add U.S. National Weather Service observations, forecasts, and alerts.
- Add Open-Meteo forecasts and wttr.in automatic location detection.
- Add metric and imperial unit switching from the bar.
- Add input validation, bounded HTTPS requests, stale-response isolation, and
  dependency-free model tests.
